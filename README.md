# 球墨铸铁金相智能分析工具 (Metallographic Analysis Tool)

本项目是一个基于计算机视觉（Computer Vision）和 Python 的球墨铸铁金相自动分析桌面软件。旨在替代传统人工显微镜下繁琐的目测与计数工作，并严格遵循国家标准 **GB/T 9441-2021** 进行球化率评级。

## 🌟 核心功能 (Features)
- **自动光照校正**：消除显微成像中的光照不均和暗角问题。
- **精准石墨分割**：基于逐图自适应 Otsu 阈值算法，鲁棒提取石墨相。
- **粘连颗粒分离**：应用距离变换与 Voronoi 算法（类似聚类思想），实现粘连石墨的智能分割，避免误切。
- **国标级评价**：自动计算圆整度、面积占比及球化率，输出符合国标的分级报告。
- **可视化交互 GUI**：支持画笔/橡皮擦人工修正，一键生成 Excel/Word 报告。
- **腐蚀试样识别**：针对珠光体组织的特殊优化（可选）。


## 🧠 算法背景 (Algorithm)
本工具的核心算法位于 `核心算法v2.py`，主要流程：
1. 大核闭运算估计背景并进行归一化。
2. 双峰 Otsu 动态阈值提取暗相。
3. 基于欧氏距离变换的形态学清理与粘连分离。
4. 提取面积、周长、最大费雷特直径、凸度等几何特征，进行形态学分类。

## 🚀 快速开始 (Quick Start)
### 依赖环境
- Python 3.8+
- OpenCV (`pip install opencv-python`)
- CustomTkinter (`pip install customtkinter`)
- openpyxl, python-docx

### 运行方式
1. Clone 本仓库。
2. 运行 `python 金相分析工具.py` 即可启动 GUI 界面。
*(如果提供了 .exe 可执行文件，可以在 Release 里放一个压缩包，说明直接下载解压即可使用)*
